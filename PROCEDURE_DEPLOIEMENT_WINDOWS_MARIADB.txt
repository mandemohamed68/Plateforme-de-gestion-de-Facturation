--------------------------------------------------------------------------------
1. PRÉREQUIS LOGICIELS SOUS WINDOWS
--------------------------------------------------------------------------------
Assurez-vous que les logiciels suivants sont installés sur votre poste Windows :
- Node.js (version 20 ou 22 LTS) : https://nodejs.org/
- Git pour Windows : https://git-scm.com/
- MariaDB Server : https://mariadb.org/ (inclut l'outil graphique HeidiSQL)

--------------------------------------------------------------------------------
2. ACCÈS À MARIADB ET CRÉATION DE LA BASE DE DONNÉES
--------------------------------------------------------------------------------
Méthode recommandée avec HeidiSQL (Interface graphique) :
1. Ouvrez l'application "HeidiSQL" depuis le menu Démarrer.
2. Créez une nouvelle session de connexion :
   - Type réseau   : MariaDB ou MySQL (TCP/IP)
   - Hôte / IP     : 127.0.0.1 ou localhost
   - Utilisateur   : root
   - Mot de passe  : [votre mot de passe administrateur MariaDB]
   - Port          : 3306
3. Cliquez sur "Ouvrir".
4. Dans l'onglet "Requête" (ou touche F9), exécutez la création de la base :

   CREATE DATABASE IF NOT EXISTS lab_facturation_db 
   CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

   CREATE USER IF NOT EXISTS 'lab_user'@'localhost' IDENTIFIED BY 'LabPassword2026!';
   GRANT ALL PRIVILEGES ON lab_facturation_db.* TO 'lab_user'@'localhost';
   FLUSH PRIVILEGES;

--------------------------------------------------------------------------------
4. CLONAGE GIT ET INSTALLATION DES DÉPENDANCES
--------------------------------------------------------------------------------
Ouvrez PowerShell ou l'invite de commande sous Windows :

# Se placer dans votre dossier de travail
cd C:\projets

# Cloner le dépôt Git
git clone <URL_DE_VOTRE_DEPOT_GIT> lab-app
cd lab-app

# Installer les dépendances du projet
npm install

--------------------------------------------------------------------------------
5. CONFIGURATION DES VARIABLES D'ENVIRONNEMENT (.env)
--------------------------------------------------------------------------------
Créez ou modifiez le fichier ".env" situé à la racine du projet (C:\projets\lab-app\.env) :

PORT=3000
NODE_ENV=production

DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=lab_user
DB_PASSWORD=LabPassword2026!
DB_NAME=lab_facturation_db

--------------------------------------------------------------------------------
6. COMPILATION ET DÉMARRAGE DE L'APPLICATION
--------------------------------------------------------------------------------
Dans votre terminal PowerShell dans le dossier "C:\projets\lab-app" :

# 1. Compiler l'application pour la production
npm run build

# 2. Démarrer le serveur
npm start

# 3. Accéder à l'application dans votre navigateur :
http://localhost:3000

Identifiants par défaut :
- Identifiant : mandemohamed68@gmail.com
- Mot de passe : admin

--------------------------------------------------------------------------------
7. CONFIGURATION DU DÉMARRAGE AUTOMATIQUE AVEC PM2 (RECOMMANDÉ)
--------------------------------------------------------------------------------
Pour que le serveur reste actif en arrière-plan et redémarre avec Windows :

npm install -g pm2
pm2 start dist/server.cjs --name "lab-facturation-app"
pm2 save

# Optionnel : Démarrage automatique au démarrage de la session Windows
npm install -g pm2-windows-startup
pm2-startup install
pm2 save

--------------------------------------------------------------------------------
8. OUVERTURE DU PARE-FEU WINDOWS (POUR ACCÈS SUR LE RÉSEAU LOCAL)
--------------------------------------------------------------------------------
Pour que les autres ordinateurs de la clinique / du laboratoire puissent accéder
à l'application via le réseau local :

1. Ouvrez PowerShell en tant qu'Administrateur.
2. Exécutez la commande :

New-NetFirewallRule -DisplayName "App Laboratoire Facturation (Port 3000)" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow

3. Les postes clients pourront se connecter en tapant dans leur navigateur :
   http://192.168.1.X:3000  (en remplaçant par l'adresse IP de votre serveur Windows)
